# App Store metadata push — setup & notes

> `fastlane/README.md` is auto-generated by fastlane (overwritten every run).
> Keep human docs here in `SETUP.md` instead.

Pushes the App Store **listing text** for all localizations in one command.
Metadata only — no binary, no screenshots.

## Localizations
`en-US`, `en-GB` (primary), `de-DE`, `fr-FR`, `it`, `es-ES`.
Each has: `name`, `subtitle`, `keywords`, `promotional_text`, `description`,
`release_notes`, `support_url`.

## Lanes
- `bundle exec fastlane verify` — read-only: confirms API auth + that an editable
  version exists. Run this anytime to sanity-check.
- `bundle exec fastlane preview` — opens an HTML preview of what would upload;
  answer `n` to abort. Nothing is written.
- `bundle exec fastlane metadata` — pushes all localizations to the current
  editable version. Does NOT submit for review.

## One-time setup
1. UTF-8 locale + ASC API key go in `fastlane/.env` (git-ignored). Copy the
   template: `cp fastlane/.env.example fastlane/.env` and fill in `ASC_KEY_ID`,
   `ASC_ISSUER_ID`, `ASC_KEY_PATH` (absolute path to the `.p8`, kept OUTSIDE the
   repo). fastlane auto-loads `.env` — no per-session exporting.
2. `bundle install` (uses the repo `Gemfile`). Always run via **bundler** —
   Homebrew's fastlane is broken under Ruby 4.0 (missing `logger`).

## Important caveats
- **Editable version required.** `metadata` writes to whatever version is in
  "Prepare for Submission". Verify with `fastlane verify`.
- **FR / IT / ES descriptions + promo are adapted translations**, not native —
  have a native speaker sanity-check before a final submit. Keyword fields are
  Astro-data-driven (see `memory/aso-de-fr-keyword-allocation.md`).
- **EULA + privacy links are mandatory in every description** (App Review
  3.1.2(c)). Already present in each `description.txt` — keep them on any edit.
- **Names change per locale** (e.g. `Recurra: Abonnement Tracker`). Name edits
  ride with the version submit.
- **Screenshots are not managed here.** French set is in `screenshots/french/`;
  upload/localize in ASC separately.
